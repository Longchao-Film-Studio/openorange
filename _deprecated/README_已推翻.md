## 重要的教训

### 1. 反复给出"最终根因"，每次都错

上表 17 份报告，时间跨度从 4:00 到 17:00，**每一份都自称是最终结论**。
这说明：**在证据不足时下结论 = 浪费**。

### 2. 拿"空壳签名"当"源码"读

`Il2CppDumper/DummyDll/` 里的程序集**方法体是空的**（`Login() { }`），
只保留类名/方法名/字段偏移/RVA。

**AOT 编译的 native 代码没有 IL 可反编译** —— 必须反汇编机器码，或用 Ghidra。

### 3. 没读工作区就开工

曾多次出现：重新扫描 FPX.dll 端点表 / 重新解析 FPX_Login 反汇编 / 重新下载工具，
**而这些早已完成并记录在 `docs/CLEAN_STATUS.md` 和 `docs/RE_INVENTORY.md`**。

**规则：动手前先读 `docs/WORKSPACE_INDEX.md`。**
