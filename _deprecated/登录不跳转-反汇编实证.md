### 3.3 还原出的逻辑

```csharp
// FPXSDKLoad.OnFPXCallback(string module, string func, string result)
// RVA 0x12CDEA0

// 1. 首次进入: 初始化 16 个字符串字面量 (0x12CDED0~0x12CDF8B)

// 2. 判断是不是 init 回调
if (String.op_Equality(module, "platform"))      // 0x12CE16D
{
    if (String.op_Equality(func, "init"))        // 0x12CE187
    {
        // ---- init 分支 ----
        var d = FPXParser.Parse(result);         // 0x12CE1A2
        object code;
        d.TryGetValue("code", out code);         // 0x12CE212
        bool ok = (code != null && (long)code == 1);
        FPXSDKAPI.SdkIsInitialized = ok;         // 0x12CE262
        Debug.Log(...);                          // 0x12CE28C

        if (!SdkIsInitialized)                   // 0x12CE2BC
        {
            Debug.Log(String.Format(...));      // 0x12CE2D9
            FPXSDKLoad.Clear();                  // 0x12CE346
            // -> 走 Clear 后的回调
        }
        else
        {
            FPXSDKLoad.OnAppStartUp();           // 0x12CE385  ★
            FPXSDKAPI.SdkIsInitialized = true;
            FPXJson.Serialize(...);              // 0x12CE3EC
            var plat = FPXInternal.GetPlatform();// 0x12CE40B
            invoke delegate(module, func, result); // 0x12CE435  ★ 回调出去
        }
        return;
    }
}

// 3. 其他回调 (login 等) -> 0x12CE46F
if (!SdkLuaApiInitialized_这里) return;          // 0x12CE47D
Debug.Log(String.Concat("FPXSDKLoad OnFPXCallback Module : ", module, ...));
... 同样构造 delegate 参数 ...
invoke delegate(module, func, result);           // 0x12CE435
return;
```

### 3.4 那么回调交给谁了?

答案在 `0x12CE435` 那条 `call 0x5C40` —— **IL2CPP 的 delegate 调用桩**。

`FPXSDKLoad` 保存了一个**委托字段** `OnCompletedCb`(类型 `Action<bool>`),
它把回调转发给**这个委托**, 而不是给 `FPXSDKBridge`。

而 `Action<bool>` 这个签名 **只能接收 bool, 收不了 (module, func, result) 三个字符串**。

看 `FPXSDKLoad.Start` 的签名:

```csharp
public static void Start(Action<bool> onCompleted)   // RVA 0x12CE8B0
```

## 四、最终结论

> ### `FPXSDKLoad` 与 `FPXSDKBridge` 是**两条互不相通的独立通路**。
>
> `FPXSDKLoad.OnFPXCallback` **不转发**给 `FPXSDKBridge` —— 反汇编已证明
> 它一次都没有调用 `FPXSDKBridge` 的任何方法。

### 那么游戏怎么进?

`FPXSDKBridge.Init()` 里的 `FPX.InitCallBack(...)` 是**第二次注册**。
关键问题是: **`FPX.InitCallBack` 第二次调用时, 是覆盖还是并存?**

这需要反汇编 `FPX.InitCallBack` (RVA `0x12CFE30`)。**这是下一个必做步骤。**
